## Vosk English (India) model

This repository bundles vosk-model-small-en-in-0.4, an Indian English speech-recognition model from the Vosk project. The Vosk model catalog lists this model under the Apache License 2.0. The model is approximately 57 MB unpacked and is used locally by AURA for offline voice commands.

- Model catalog: https://alphacephei.com/vosk/models
- Vosk API: https://github.com/alphacep/vosk-api
