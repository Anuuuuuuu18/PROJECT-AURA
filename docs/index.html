Small gestures, useful actions

Meet the controls.

The desktop controller combines hand landmarks, a smoothing filter, one-action click detection, and a local voice listener.

☝️

One-finger scroll

Keep the familiar pointer gesture. Vertical index-finger motion scrolls in the direction you move.

🤏

Pinch to click

Bring thumb and index finger together for a single click, with a cooldown against repeats.

🗣️

Offline voice

Vosk listens locally for app commands such as “open Chrome,” plus pause and resume phrases.

✊

Emergency pause

Hold a fist for one second, say “pause AURA,” or press P to stop desktop actions.

✋

Safe resume

Live mode opens paused. Resume with an open palm or a spoken command when you’re ready.

02 · INSTALL

Create a virtual environment and install the listed Python packages.

03 · START

Trust matters

Private by default.

The local app and the web demo have different jobs—and neither needs to send your hand or voice data to a server.

🔒 Local desktop app

MediaPipe processes webcam frames locally. Vosk recognizes speech offline. Audio and video are not uploaded. PyAutoGUI acts only when live mode is enabled and resumed.

🌷 GitHub Pages demo

The web page is an interaction simulation. It does not request camera or microphone access and cannot control the visitor’s desktop.
